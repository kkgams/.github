# Your game. Your editor.

**GAMS** lets you build a game-editing workspace with the tools your project needs.

[![GAMS workspace with a file browser, live bullet-pattern preview, and node-based build pipeline.](https://kkgams.github.io/gams/images/projects/gams-workspace.jpg)](https://kkgams.github.io/gams/)

### [Try GAMS →](https://kkgams.github.io/gams/)

Explore the workspaces and download the desktop app. [Read the documentation](https://kkgams.github.io/gams/docs/).

## Make it yours

Bring together editors for maps, animation, code, and data. Combine Views, plugins, and themes into a workspace for your game.

## Help build GAMS

Report a bug, improve an existing tool, or create one that's missing.
